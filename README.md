# CSE370_LabProject_G11
Project: Local Repair & Maintenance Service Directory
Technology: TailwindCSS, ReactJS, PHP, MySQL
Authentication: None (no login or registration)

1. Browse Service Provider Directory – Display all available repair service providers with their business name, contact information, location and estimated prices.

2. Categorize Repair Services – Organize repair services into categories such as Electronics, Home Appliances, Bicycle, Furniture and General Maintenance.

3. Search Providers by Area – Allow customers to find repair service providers based on their city, area or location.

4. Filter Providers by Service Type and Price – Filter providers based on repair category, specific service and estimated price range.

5. Compare Service Prices – Allow customers to compare estimated repair prices from multiple providers offering the same service.

6. Submit Repair Inquiry Without Login – Allow customers to submit repair requests by providing their name, phone number, service type and problem description. Generate a unique reference number automatically.

7. Track Repair Inquiry Using Reference Number – Allow customers to check their inquiry status using their reference number and phone number.

8. Manage Repair Status and Service History – Provide a management dashboard to view inquiries, update repair statuses (Pending, Accepted, In Progress, Completed, Rejected) and maintain status history.

9. Generate Service Demand and Pricing Reports – Generate reports showing total inquiries, popular repair categories, provider demand, average service prices and monthly service demand.

Database focus:

Relational database design

Primary and foreign keys

One-to-many and many-to-many relationships

SQL JOINs

Subqueries

Aggregate functions (COUNT, AVG, SUM)

GROUP BY and ORDER BY

Data filtering and status tracking
